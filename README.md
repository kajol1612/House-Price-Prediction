# House-Price-Prediction  
A complete end-to-end regression project that predicts house prices using real-world housing features like area, number of rooms and location. The project demonstrates the full ML pipeline from data preprocessing to model evaluation and visualization.
- Other housing features

## ⚙️ Tools & Technologies
Python, Pandas, Scikit-learn, Matplotlib, Seaborn

## 🔍 Machine Learning Models Used
- Linear Regression
- Random Forest Regressor

## 📊 Project Workflow
1. Data Cleaning & Preprocessing
2. Feature Engineering
3. Model Training
4. Model Evaluation (R2 Score, MAE, RMSE)
5. Price Prediction
